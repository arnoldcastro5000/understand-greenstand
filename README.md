# understand-greenstand

Machine-generated documentation for the core-active Greenstand repository estate.

Each source repo has one directory under [`repos/`](./repos/). A directory holds that
repo's `knowledge-graph.json` plus rendered domain and onboarding markdown, produced by
the [Understand-Anything](https://github.com/) skill suite (`understand`,
`understand-domain`, `understand-onboard`).

The layout is regenerate-ready. See [`docs/regenerating.md`](./docs/regenerating.md) for
how to refresh a repo's docs.

## Scope

The estate covers 13 core-active, public, Greenstand-authored repositories: the core
Tree Tracker services, the wallet stack, the admin tools, the web map, the mobile app,
the data-ingest services, and the infrastructure repo. Fork repos, private repos, and
dormant repos are out of scope.
