## Domains

### Map Exploration & Search

Renders the interactive Leaflet-based map of tracked trees, letting visitors pan, zoom, filter by planting date, and search for trees, planters, or species. Keeps the browser URL synchronized with map state so views are shareable and restorable.

**Terms:** Map instance, Marker/cluster, Timeline filter, Search result, URL query state

**Rules:**

- Map view state (bounds, filters, selection) must always be reflected in the URL so views are shareable and bookmarkable.
- Timeline date filter cannot select a range beyond the current date.

**Flows:**

- **Browse the Interactive Map** (`GET / (pages/index.js renders the map)`): Loads the shared Leaflet map instance, renders tree markers/clusters, and lets a visitor pan, zoom, or click a marker to open its detail drawer.
- **Filter Trees by Planting Date** (`GET /filter?timeline=... or Timeline widget on map`): Lets a visitor restrict the visible trees on the map to a specific date range via the Timeline picker or the standalone filter page.
- **Search for Trees, Planters, and Species** (`SearchButton click or GET /search`): Lets a visitor type a keyword to find matching trees, planters, or species, browse recent search history, and jump to a result.

### Entity Profile Pages

Renders detail pages for individual trees, captures, planters, and organizations fetched from the treetracker-query-api, showing photos, species, capture location, and related people or organizations. These are the destination pages when a visitor selects a marker or search result on the map.

**Terms:** Tree, Capture, Planter (Grower), Organization (Stakeholder), Species

**Rules:**

- Detail pages are statically or server-rendered per id and must gracefully handle missing or loading data via skeleton loaders.
- Organization pages aggregate trees, associates, and species counts concurrently rather than sequentially.

**Flows:**

- **View Tree Detail** (`GET /trees/[treeid]`): Renders an individual tree's detail view: photo, species, capture location, and associated planter and organization info.
- **View Capture Detail (v2)** (`GET /v2/captures/[captureid]`): Renders an individual capture's detail view: photo, grower, stakeholder/organization info, and geolocation.
- **View Planter Profile** (`GET /planters/[planterid]`): Renders a planter (grower) profile: map focus, bio/quote, species planted, and associated organizations.
- **View Organization Profile** (`GET /organizations/[organizationid]`): Renders an organization's public profile: map focus, description, associated species, and planters.

### Blockchain Wallet & Token Tracking

Displays blockchain-backed wallet and token pages, showing which trees a wallet holds and a token's ownership and transaction provenance. Represents the tokenization layer that ties physical trees to verifiable digital ownership records.

**Terms:** Wallet, Token, Transaction, Species-by-wallet

**Rules:**

- Token detail must show full ownership/transaction history for provenance and trust.
- Wallet statistics are aggregated by token region.

**Flows:**

- **View Wallet Profile** (`GET /wallets/[walletid]`): Renders a wallet's public profile: map view, token-region statistics, token list, and species planted under the wallet.
- **View Token Detail & Provenance** (`GET /tokens/[tokenid]`): Renders a tree token's detail view: tree photo, capture location, and ownership/transaction history.

### Impact & Leaderboard

Surfaces aggregate impact statistics and highlights on the homepage and the 'Top' page: a country leaderboard, featured trees/planters sliders, and a world-map continent view, to showcase the reforestation network's scale.

**Terms:** Country leaderboard entry, Featured tree, Featured planter, Continent tree count

**Rules:**

- Leaderboard ranks countries by trees planted, with medal ribbons for the top 3.
- Featured content is fetched at build time via getStaticProps.

**Flows:**

- **View Top / Leaderboard Page** (`GET /top`): Shows featured trees, featured planters, and a per-country leaderboard on an interactive world map.
- **View Homepage Impact Highlights** (`GET /`): Renders the landing page hero and impact stat cards that promote the network's reforestation impact.

### Site Administration & Customization

Lets authorized administrators reconfigure the deployed site's branding, navbar, initial map location, and full Material UI theme (palette, typography, fonts) through a live playground, then persists those choices.

**Terms:** Dashboard config (navbar items, logo, map location), Theme (palette, typography, fonts), RPT/permission token

**Rules:**

- Admin pages require a valid Keycloak RPT/permission token before rendering editable controls.
- Theme and dashboard config changes persist to local storage and can be server-supplied on load.

**Flows:**

- **Admin Authentication & Authorization** (`GET /admin`): Authenticates an admin via Keycloak SSR and conditionally renders admin UI based on decoded entitlements.
- **Configure Dashboard Branding** (`GET /admin/global`): Lets an admin edit the navbar links, logo, and initial map location, persisting changes to local storage.
- **Customize Theme** (`GET /admin/theme`): Lets an admin live-edit the site's Material UI theme (palette, typography, fonts, light/dark mode) with an iframe preview.

### Authentication & Sharing

Provides OIDC/Keycloak sign-in and sign-out for the whole app, and lets any visitor share a tree or entity page via a copyable link, embeddable iframe snippet, or social post.

**Terms:** OIDC user session, Share link, Embed snippet

**Rules:**

- Sign-in uses a redirect-based OIDC flow via Keycloak; UserAvatar and admin gating only render when authenticated.
- Share dialog offers both a canonical link and an embeddable iframe snippet.

**Flows:**

- **Sign In / Sign Out** (`SignInButton / SignOutButton click`): Authenticates a visitor against Keycloak via OIDC redirect and reflects the session in the navbar.
- **Share an Entity Page** (`Share icon click on a profile page`): Lets a visitor copy a shareable link, generate an embeddable iframe snippet, or post an entity page to social media.
